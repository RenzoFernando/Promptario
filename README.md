Promptario es una biblioteca web para centralizar y reutilizar prompts. Permite localizar contenido mediante búsqueda, organizarlo con categorías y favoritos, consultarlo en varias vistas y copiarlo cuando se necesita.

## Características

- Crear, consultar, editar y eliminar prompts con acceso de edición protegido por PIN.
- Buscar por título, contenido o categoría.
- Organizar prompts con categorías y favoritos.
- Alternar entre cuadrícula, lista extendida e índice de títulos.
- Contraer la navegación lateral y ordenar la colección.
- Mantener una biblioteca privada separada, accesible únicamente con autorización.
- Copiar prompts y escribirlos con vista previa de Markdown.
- Recuperar el acceso administrativo mediante un enlace de un solo uso.
